# Installation

SDF ships as a single static binary with no runtime dependencies. Pick the method that fits your workflow.

---

## Homebrew (macOS and Linux)

```bash
brew install pavelpascari/tap/sdf
```

Updates are handled by `brew upgrade`.

---

## Go install

If you have Go 1.24 or later:

```bash
go install github.com/pavelpascari/sdf@latest
```

The binary is placed in `$GOPATH/bin` (ensure this is on your `$PATH`).

---

## Binary download

Pre-built binaries are available for every platform on the [Releases page](https://github.com/pavelpascari/sdf/releases).

| Platform | Architecture | File |
|---|---|---|
| Linux | x86_64 | `sdf_linux_amd64.tar.gz` |
| Linux | ARM64 | `sdf_linux_arm64.tar.gz` |
| macOS | Intel | `sdf_darwin_amd64.tar.gz` |
| macOS | Apple Silicon | `sdf_darwin_arm64.tar.gz` |
| Windows | x86_64 | `sdf_windows_amd64.zip` |
| Windows | ARM64 | `sdf_windows_arm64.zip` |

Each archive contains the binary and a SHA256 checksum file. Verify before running:

```bash
# Download and verify (Linux x86_64 example)
curl -LO https://github.com/pavelpascari/sdf/releases/latest/download/sdf_linux_amd64.tar.gz
curl -LO https://github.com/pavelpascari/sdf/releases/latest/download/sdf_linux_amd64.tar.gz.sha256
sha256sum -c sdf_linux_amd64.tar.gz.sha256
tar xzf sdf_linux_amd64.tar.gz
mv sdf /usr/local/bin/
```

## Build from source

```bash
git clone https://github.com/pavelpascari/sdf.git
cd sdf
make build      # → bin/sdf
make install    # → $GOPATH/bin/sdf
```

Requires Go 1.24+.

---

## Runtime dependencies

SDF shells out to other CLIs rather than reimplementing their logic:

| Dependency | Required for | Install |
|---|---|---|
| `git` | All operations | Comes with your OS |
| `gh` | PR operations (`sdf pr`, `sdf sync`) | [cli.github.com](https://cli.github.com) |
| `claude` | AI features | [claude.ai/code](https://claude.ai/code) |

The Claude CLI is optional. Without it, `sdf sync` will open `$EDITOR` on conflicts instead of resolving them automatically.

Verify everything is in place:

```bash
sdf doctor
```

## Shell completion

```bash
# bash
sdf completion bash > /etc/bash_completion.d/sdf

# zsh
sdf completion zsh > "${fpath[1]}/_sdf"

# fish
sdf completion fish > ~/.config/fish/completions/sdf.fish
```

---

## Uninstall

Remove the binary from wherever you placed it. SDF writes no data outside the repositories you use it in (plus `~/.config/sdf/config.json` for global config).

```bash
# If installed via Homebrew
brew uninstall sdf

# If installed manually
rm $(which sdf)
rm -rf ~/.config/sdf
```
